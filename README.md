
# Биндер для Amazing Online

Начнём с того что данный скрипт полностью написан на ИИ, и за правильность кода ручалась полностью она, не надо меня дрочить тем что скрипт хуйни, не нравится - не пользуйтесь. ( Прошу, если есть критика - пишите, отвечу )


## Зависимости, установка, использование

Зависимости

```bash
  1. Python 3.11 ( на более новых или раних версиях скрипт не тестировал )
  2. Библиотеки keyboard и Pillow.
  3. Права администратора.
  4. Прямые руки.
```

Установка скрипта

```bash
  1. Скачать архив Python 3.11
  2. Скачать архив ( Code -> Download zip )
  3. Открыть консоль в папке.
  4. Прописать команду: pip install -r requirements.txt
  5. Запустить start.bat ( последующий запуск через него )
```

Использование скрипта

```bash
  1. Запусти файл start.bat
  2. Дальше больше нехуй объяснять.
```
## Features

- Автоматические доклады на постах/патрулях ( а так то всё, обычный биндер )


## FAQ

#### Скрипт нарушает правила проекта?

На момент публикации ( а именно 08.11.2026 ) правила проекта не нарушает, т.к. взаимодействие с памятью игры осуществляет UDF.ahk скрипт который был опубликован разработчиком проекта Amazing Online, Максимом Снегирёвым в данной теме -> [Страница форума](https://forum.amazing-online.com/threads/ahk-crmp-udf-0-3-7-r3.321129/).

#### Зачем скрипту нужны права администратора?

Скрипту нужны права администратора для коректной работы регистратора нажатий на клавиши ( и то, он не идеален )

#### Что делать если у меня ошибка или скрипт не запускается?

Проверь правильность установки всего что нужно в пункте выше, если всё правильно, пиши мне.
